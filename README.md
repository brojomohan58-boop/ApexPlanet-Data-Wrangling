# 📌 Project Overview

This repository contains the first two internship tasks completed during the **ApexPlanet Software Pvt. Ltd. Data Analytics Internship**.

The project demonstrates the complete analytical workflow beginning with **raw data cleaning**, followed by **SQL-based business analysis**, **Exploratory Data Analysis (EDA)**, **statistical interpretation**, and finally a **business dashboard mock-up** for decision makers.

The objective was to transform raw sales data into meaningful business insights using industry-standard analytics tools.

# 📌 Key Insights

### Data Wrangling

- Missing values handled
- Duplicate records removed
- Consistent formatting established
- Dataset prepared for analytics

---

### SQL Analysis

- Electronics generated the highest revenue.
- Monthly revenue remained relatively stable.
- Major cities contributed almost equally to revenue.
- Most customers were one-time buyers.
- Customer retention opportunity identified.

---

### Exploratory Data Analysis

- Unit Price and Quantity are the strongest drivers of Total Sales.
- Age has minimal linear relationship with revenue.
- Category has a stronger impact on sales than customer demographics.
- Revenue distribution is balanced across gender and age groups.
